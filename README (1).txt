EKAVORA website starter
=======================

Files:
- index.html: website structure
- style.css: visual design and responsive layout
- script.js: mobile navigation and current year

Preview:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Internet is needed for Google Fonts and the remote background photographs.

Before publishing:
- Replace hello@ekavora.com with your real contact email.
- Replace sample imagery with photos/posters you own or have permission to use.
- Check that EKAVORA and your preferred domain are available before using them commercially.
- This is a static starter website; the contact link opens the visitor's email app and does not store form submissions.

Free hosting option:
GitHub Pages can host a static website. You will need a GitHub account and to upload these files to a repository.

Logo update:
- Custom EKAVORA logo image is included at assets/ekavora-logo.jpg.
- Keep the assets folder alongside index.html when uploading to GitHub.
- Upload/replace index.html, style.css, and assets/ekavora-logo.jpg in your repository.
